### 1.2 産業廃棄物処理業（第14条）

#### 許可の基本構造

| 項目 | 収集運搬業（§1） | 処分業（§6） |
|------|-----------------|-------------|
| 許可権者 | 都道府県知事 | 都道府県知事 |
| 更新期間 | 5年以上（政令で定める期間） | 同左 |
| 許可基準 | 施設・能力基準 + 欠格要件 | 同左 |
| 条件付与 | §14⑪: 生活環境の保全上必要な条件 | 同左 |
| 優良認定 | 能力・実績に応じ更新期間が延長可能 | 同左 |

#### ライフサイクルイベント一覧

| イベント | 根拠条文 | 手続 | 備考 |
|---------|---------|------|------|
| **新規許可** | §14①⑥ | 都道府県知事の許可 | 収集運搬業・処分業それぞれ |
| **許可更新** | §14②⑦ | 都道府県知事の許可 | 5年以上の政令期間ごと |
| **事業範囲の変更** | §14の2① | 都道府県知事の許可 | 事業の一部廃止は届出で足りる |
| **事業の一部廃止** | §14の2①但書 | 届出（§14の2③→§7の2③準用） | 許可不要 |
| **事業の全部廃止** | §14の2③→§7の2③準用 | 都道府県知事への届出 | 遅滞なく届出 |
| **住所等の変更** | §14の2③→§7の2③準用 | 都道府県知事への届出 | 環境省令で定める事項 |
| **欠格要件該当の届出** | §14の2③→§7の2④⑤準用 | 都道府県知事への届出 | |
| **困難通知** | §14⑬ | 委託者への書面通知 | 適正処理が困難になったとき |
| **廃止後の通知** | §14の2④ | 委託者への書面通知 | 未了の収集運搬・処分がある場合 |
| **事業停止命令** | §14の3 | 都道府県知事の命令 | 違反行為・基準不適合・条件違反 |
| **許可の取消し（必須）** | §14の3の2① | 都道府県知事の処分 | 暴力団関連・重大違反・不正取得 |
| **許可の取消し（裁量）** | §14の3の2② | 都道府県知事の処分 | 基準不適合・条件違反 |
| **取消後の通知** | §14の3の2③ | 委託者への書面通知 | 未了処理がある場合 |
| **名義貸しの禁止** | §14の3の3 | ― | 違反は罰則あり |

#### 事業範囲の変更で許可が必要な事項（§14の2①）

- 取り扱う廃棄物の種類の追加
- 処分方法の追加・変更
- 事業区域の拡大
- 施設の変更（能力増強等）

> **注意**: 事業の一部廃止（縮小方向の変更）は届出のみで許可不要。

#### 事業停止命令の事由（§14の3）

1. 違反行為をしたとき（教唆・幇助を含む）
2. 施設・能力が基準に適合しなくなったとき
3. 許可に付した条件に違反したとき

#### 許可の取消し事由（§14の3の2）

**必須取消し（§14の3の2①）** — 該当したら取り消さなければならない:
1. 暴力団関連の欠格要件に該当
2. 役員等が暴力団関連の欠格要件に該当
3. 役員等が§7⑤④号ホ（許可取消歴）に該当
4. その他の欠格要件に該当（上記以外）
5. 情状が特に重い違反、又は停止命令違反
6. 不正手段による許可・変更許可の取得

**裁量取消し（§14の3の2②）** — 取り消すことができる:
- 基準不適合、条件違反

## 2. 処理施設（施設の許可）

### 2.1 一般廃棄物処理施設（第8条・第9条）

#### 許可の基本構造（§8）

| 項目 | 内容 |
|------|------|
| 対象施設 | ごみ処理施設（政令指定）、し尿処理施設、最終処分場（政令指定） |

| 使用前検査 | 都道府県知事の検査合格後に使用可能 |

|---------|---------|------|------|

| **施設の譲受け** | §9の5① | 都道府県知事の許可 | 許可施設設置者の地位承継 |

#### 変更許可が必要な事項（§9① → §8②四号〜七号）

| 号 | 事項 |
|----|------|
| 四号 | 処理する廃棄物の種類 |
| 五号 | 処理能力（最終処分場: 面積・埋立容量） |
| 六号 | 位置、構造等の設置に関する計画 |
| 七号 | 維持管理に関する計画 |

#### 市町村設置施設の特例（§9の3）

市町村が設置する一般廃棄物処理施設は許可不要だが届出義務あり。変更についても同様の届出義務。

#### 変更許可が必要な事項（§15の2の6① → §15②四号〜七号）

| 号 | 事項 |
|----|------|
| 四号 | 処理する産業廃棄物の種類 |
| 五号 | 処理能力（最終処分場: 面積・埋立容量） |
| 六号 | 位置、構造等の設置に関する計画 |
| 七号 | 維持管理に関する計画 |

#### 改善命令・使用停止命令の事由（§15の2の7）

1. 構造・維持管理が技術基準又は設置計画・維持管理計画に不適合
2. 設置者の能力が環境省令基準に不適合
3. 違反行為（教唆・幇助を含む）
4. 許可条件への違反

#### 許可の取消し事由（§15の3）

**必須取消し（§15の3①）**:
1. 設置者が欠格要件（§14⑤②号イ〜ヘ）に該当
2. 情状が特に重い違反、又は改善命令・停止命令違反
3. 不正手段による設置許可・変更許可の取得

**裁量取消し（§15の3②）**:
- 基準不適合、条件違反、維持管理積立金の未積立

## 3. 変更事由の分類とシステム対応

### 3.1 処理業の変更事由マトリクス

| 変更事由 | 法的手続 | システム上の操作 |
|---------|---------|----------------|
| 新規許可 | 許可 | 新規登録 |
| 許可更新 | 許可 | 更新（旧版CLOSE + 新版INSERT） |
| 事業範囲変更（拡大） | 変更許可 | 変更（旧版CLOSE + 新版INSERT） |
| 事業範囲変更（縮小＝一部廃止） | 届出 | 変更（旧版CLOSE + 新版INSERT） |
| 住所等変更 | 届出 | 修正（UPDATE） |
| 事業全部廃止 | 届出 | 廃止（ステータス変更） |
| 事業停止命令 | 行政処分 | 取消（ステータス変更） |
| 許可取消し | 行政処分 | 取消（ステータス変更） |

### 3.2 処理施設の変更事由マトリクス

| 変更事由 | 法的手続 | システム上の操作 |
|---------|---------|----------------|
| 設置許可 | 許可 | 新規登録 |
| 処理廃棄物種類の変更 | 変更許可 | 変更（旧版CLOSE + 新版INSERT） |
| 処理能力の変更 | 変更許可 | 変更（旧版CLOSE + 新版INSERT） |
| 設置計画の変更 | 変更許可 | 変更（旧版CLOSE + 新版INSERT） |
| 維持管理計画の変更 | 変更許可 | 変更（旧版CLOSE + 新版INSERT） |
| 軽微な変更 | 届出 | 修正（UPDATE） |
| 氏名等の変更 | 届出 | 修正（UPDATE） |
| 施設の廃止 | 届出/確認 | 廃止（ステータス変更） |
| 施設の休止 | 届出 | 休止（ステータス変更） |
| 休止施設の再開 | 届出 | 再開（ステータス変更） |
| 改善命令 | 行政処分 | （記録管理） |
| 使用停止命令 | 行政処分 | 取消（ステータス変更） |
| 許可取消し | 行政処分 | 取消（ステータス変更） |
| 施設の譲受け・借受け | 許可 | 事業者の変更 |

### 3.3 システムの3操作パターンとの対応

本システムでは変更を3パターンに分類して管理する:

| 操作 | 意味 | DB処理 | 対応する法的事由 |
|------|------|--------|----------------|
| **更新/変更** | 新バージョン作成 | 旧版CLOSE + 新版INSERT | 許可更新、事業範囲変更、施設変更許可 |
| **修正** | 既存データの直接修正 | UPDATE | 軽微な変更、氏名変更、入力誤り訂正 |
| **状態変更** | ライフサイクル遷移 | UPDATE（日付フィールド） | 廃止、取消、休止、再開、復活 |

### 3.4 許可タブで管理する品目変更

許可タブの品目（取扱品目）は、事業範囲の変更（§14の2①）に直結する。

- **品目の追加**: 事業範囲の拡大 → 変更許可が必要
- **品目の削除**: 事業の一部廃止 → 届出のみ
- **品目の変更なし**: 許可更新時にそのままコピー

### 3.5 施設タブで管理する処理能力変更

施設タブの処理能力は、§15②五号（処理能力）の変更に該当する。

- **処理能力の増減**: 変更許可が必要（§15の2の6①）
- **処理廃棄物種類の変更**: 変更許可が必要（§15の2の6①）
- **軽微な変更**: 届出のみ（§15の2の6①但書）

#### 補足: 事業停止命令（S3）の扱い

事業停止命令（§14の3）は許可の取消し（§14の3の2）とは異なる:

- **停止命令**: 期間を定めた一時的な事業の全部又は一部の停止。期間満了で自動的に事業再開可能。許可自体は有効のまま。
- **取消し**: 許可そのものが消滅する。再度事業を行うには新規申請が必要。

現行システムでは要件定義時に「取消のみで十分」と判断し、停止命令を独立した状態として管理していない。停止命令の発令頻度が極めて低いこと、停止命令中も許可自体は有効であることが理由。将来管理が必要になった場合は、上記の停止命令日・停止期間・停止範囲の追加が必要。

#### 補足: 最終処分場の特殊な廃止プロセス
