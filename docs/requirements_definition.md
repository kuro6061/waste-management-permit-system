**バージョン**: 1.0
**作成日**: 2026-03-01

## 1. システム概要

### 1.1 目的

廃棄物処理法に基づく業許可・施設許可の情報を一元管理するシステム。
産業廃棄物と一般廃棄物の両方の許可を同一システムで管理する。

### 1.2 利用者

| 項目 | 内容 |
|------|------|
| 利用組織 | 政令市・中核市の廃棄物許可担当課 |
| 同時利用者数 | 2〜5人（小規模チーム） |
| ユーザー権限 | 不要（全員同一権限） |

### 1.3 技術基盤

| 項目 | 内容 |
|------|------|
| アプリケーション | HTA（HTML Application） |
| データベース | Microsoft Access（JET SQL） |
| 共有方式 | 共有フォルダ上にAccess DBを配置 |
| ロジック | app_logic.js（SQLビルダー等、HTA・MCP・テストから共用） |

### 1.4 対象自治体

秋田市を初期導入先とするが、**他の自治体でも利用可能なユニバーサル設計**とする。
自治体固有の設定（許可番号体系等）はマスタデータで柔軟に定義できること。

## 2. 管理対象

### 2.1 廃棄物種類

| 種類 | 法的根拠 | 許可権者 |
|------|---------|---------|
| 産業廃棄物 | 廃棄物処理法 第14条 | 都道府県知事（政令市・中核市は市長） |
| 特別管理産業廃棄物 | 廃棄物処理法 第14条の4 | 同上 |
| 一般廃棄物 | 廃棄物処理法 第7条 | 市町村長 |

### 2.2 許可区分

#### 産業廃棄物（現行4区分・変更なし）

| 許可区分ID | 許可区分名 |
|-----------|-----------|
| 1 | 産業廃棄物処分 |
| 2 | 産業廃棄物処分・特管 |
| 3 | 産業廃棄物収集運搬 |
| 4 | 産業廃棄物収集運搬・特管 |

#### 一般廃棄物（新規追加2区分）

| 許可区分ID | 許可区分名 |
|-----------|-----------|
| (新規) | 一般廃棄物収集運搬 |
| (新規) | 一般廃棄物処分 |

**区別方法**: 許可区分マスタで産廃/一廃を区別する。
廃棄物種類区分マスタ（産廃/特管/一廃）を許可区分に紐づけ、検索時のフィルタリングに使用。

### 2.3 許可の有効期間

| 種類 | 有効期間 | 根拠 |
|------|---------|------|
| 産業廃棄物処理業 | 5年（優良認定は7年） | 第14条2項 |
| 一般廃棄物処理業 | 許可ごとに異なる（手入力） | 第7条（2年を下らない期間） |
| 施設許可 | 有効期間なし（廃止まで有効） | ― |

### 2.4 施設

産廃・一廃ともに**同一の施設テーブル**で管理する。
施設種別マスタで区別（中間処理施設、最終処分場、積替保管施設、一般廃棄物処理施設 等）。

一般廃棄物処理施設（第8条）の施設種別をマスタに追加する。

### 2.5 品目

産廃・一廃ともに**同一の品目マスタ**で管理する。
一般廃棄物用の品目を既存マスタに追加。

積替保管の管理は品目単位のフラグ（取扱/積替保管）で行う（現行通り）。

## 4. 許可番号

### 4.1 産業廃棄物の許可番号体系

環境省通知に基づく全国統一の11桁体系。

| 桁位置 | 内容 | 例 |
|--------|------|-----|
| 1-3桁 | 自治体コード（都道府県:001-047、政令市等:050-） | 086（秋田市） |
| 4桁目 | 業種番号 | 0-9（下表参照） |
| 5桁目 | 自由番号（自治体が独自に使用） | 0-9 |
| 6-11桁 | 固有番号（事業者固有、全国統一） | 6桁数字 |

**4桁目 業種番号:**

| 番号 | 業種 |
|------|------|
| 0 | 産廃収集運搬（積替なし） |
| 1 | 産廃収集運搬（積替あり） |
| 2 | 産廃処分業（中間処分のみ） |
| 3 | 産廃処分業（最終処分のみ） |
| 4 | 産廃処分業（中間・最終） |
| 5 | 特管収集運搬（積替なし） |
| 6 | 特管収集運搬（積替あり） |
| 7 | 特管処分業（中間処分のみ） |
| 8 | 特管処分業（最終処分のみ） |
| 9 | 特管処分業（中間・最終） |

**参考**: 平成12年度以前の都道府県は2桁コード（10桁許可番号）。本システムは10桁・11桁の両方に対応する。

### 4.2 一般廃棄物の許可番号体系

全国統一の体系は存在しない。各市町村が独自に付番する。
体系は自治体ごとに異なるため、自由入力またはマスタ定義のパターンで検証する。

### 4.3 許可番号形式マスタ（新規）

許可区分ごとに番号の検証ルール（正規表現パターン）を定義するマスタ。
これにより**自治体ごとの番号体系の違いに柔軟に対応**する。

| カラム | 型 | 説明 |
|--------|-----|------|
| 許可番号形式ID | AUTOINCREMENT | PK |
| 許可区分ID | INTEGER | 対象の許可区分 |
| パターン | TEXT | 正規表現（例: `^\d{11}$`） |
| 説明 | TEXT | 表示用の説明（例: 「11桁の数字」） |

**設定例（秋田市）:**

| 許可区分 | パターン | 説明 |
|---------|---------|------|
| 産業廃棄物処分 | `^\d{11}$` | 11桁の数字 |
| 産業廃棄物収集運搬 | `^\d{11}$` | 11桁の数字 |
| 産業廃棄物処分・特管 | `^\d{11}$` | 11桁の数字 |
| 産業廃棄物収集運搬・特管 | `^\d{11}$` | 11桁の数字 |
| 一般廃棄物収集運搬 | （未設定＝検証なし） | ― |
| 一般廃棄物処分 | （未設定＝検証なし） | ― |

パターンが未設定の許可区分は自由入力とする。

## 5. 許可ライフサイクル

既存の仕様書（permit_lifecycle_spec.md）に準拠。変更なし。

### 5.1 状態遷移

```
新規登録 → 有効
  ├── 更新 → 旧版 + 新版（同一論理ID）
  ├── 廃止 → 廃止済み（事業者の自主的廃止、14条の2第4項）
  ├── 取消 → 取消済み（行政処分、14条の3の2）
  └── 復活 → 有効に戻る（誤操作の訂正用）
```

### 5.2 一般廃棄物への適用

一般廃棄物の許可にも同一のライフサイクル（更新・廃止・取消・復活）を適用する。
法的根拠は異なるが、システム上の操作は同一。

| 操作 | 産業廃棄物 | 一般廃棄物 |
|------|-----------|-----------|
| 更新 | 14条2項 | 7条2項 |
| 廃止 | 14条の2第4項 | 7条の2第4項 |
| 取消 | 14条の3の2 | 7条の4 |

### 5.3 変更許可

許可内容の変更（品目追加等）時に、有効期限を引き継いで新バージョンを作成する機能。
既に実装済み（isChange フラグ）。産廃・一廃ともに適用。

## 6. 検索機能

### 6.1 許可検索

現行の検索条件を維持。一廃対応に伴い、許可区分フィルタで一廃の区分も選択可能にする。

| 検索条件 | 説明 |
|---------|------|
| キーワード | 許可番号 or 事業者名 |
| 基準日 | as-of検索 |
| 許可区分 | プルダウン（産廃4区分 + 一廃2区分） |
| 期限状態 | 期限切れ / 30日以内 / 90日以内 / 1年以内 / 有効 |
| 許可状態 | 有効 / 廃止 / 取消 |
| 優良認定 | ○のみ |
| 品目 | 品目選択（AND/OR） |

### 6.2 その他の検索

事業者検索・施設検索・車両検索・役員検索は現行通り。

### 6.3 期限の色分け

現行の色分け・バッジ表示を維持。能動的な通知（メール等）は不要。

| 条件 | 表示 |
|------|------|
| 取消済み | 赤系背景 |
| 廃止済み | グレー系背景 |
| 期限切れ / 期限間近 | 黄系背景 |
| 有効 | 通常背景 |

## 7. CSVエクスポート

### 7.1 対象画面

全検索画面にCSVエクスポート機能を実装する。

| 画面 | 出力内容 |
|------|---------|
| 事業者一覧 | 事業者名、住所、電話番号 等 |
| 許可検索結果 | 事業者名、許可番号、許可区分、許可日、有効期限、状態 等 |
| 施設検索結果 | 事業者名、施設種別、設置場所、許可番号 等 |
| 車両検索結果 | 事業者名、登録番号、状態 等 |
| 役員検索結果 | 事業者名、氏名、役職、状態 等 |

### 7.2 仕様

| 項目 | 仕様 |
|------|------|
| 出力内容 | 画面表示と同一の列・内容 |
| 文字コード | UTF-8（BOM付き、Excel互換） |
| 区切り文字 | カンマ |
| ファイル名 | `{画面名}_{日付}.csv`（例: `許可検索_20260301.csv`） |

## 9. スコープ外（将来検討事項）

以下は本バージョンのスコープ外とする。

| 項目 | 理由 |
|------|------|
| メール通知 | 現時点では色分けで十分 |
| 印刷帳票 | CSVエクスポートで代替 |
| 行政処分履歴（停止命令・改善命令） | 取消のみで十分 |
| ユーザー権限管理 | 全員同一権限で運用 |
| 添付ファイル管理 | 不要 |
| 備考・メモ欄 | 不要 |
| Webアプリ化 | HTAのまま運用 |
| 浄化槽保守点検業 | 対象外 |
