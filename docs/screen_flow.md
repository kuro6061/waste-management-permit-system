## 1. ページ構成

SPA方式で、全ページは `<div class="page">` として定義され、`showPage(id)` で切り替わる。

| ページID | タイトル | 概要 |
|----------|----------|------|
| `page-home` | ホーム | メニュー画面（検索・管理のエントリポイント） |
| `page-search` | 事業者検索 | 事業者名・電話番号・住所で検索 |
| `page-search-permit` | 業検索 | 許可番号・事業者名で検索（詳細フィルタ付） |
| `page-search-facility` | 施設検索 | 設置場所・許可番号・事業者名で検索 |
| `page-search-vehicle` | 車両検索 | 登録番号・事業者名で検索 |
| `page-search-officer` | 役員検索 | 氏名・役職名・事業者名で検索 |
| `page-list` | 一覧表示 | 事業者一覧等の汎用リスト |
| `page-detail` | 事業者詳細 | タブ構成（基本情報/許可/施設/車両/役員） |
| `page-business-form` | 事業者フォーム | 事業者の新規登録・編集 |
| `page-settings` | 設定 | DB接続、マスター管理、テーマ切替 |
| `page-master` | マスター一覧 | マスターデータの一覧表示 |
| `page-master-form` | マスターフォーム | マスターデータの新規・編集 |

## 6. 許可タブ

### 6.1 許可一覧 (`tab-permits`)

`loadPermitsForBusiness(businessId)` で表示。カードレイアウト。

**各カードの表示内容**:
- ステータスバッジ（有効/期限切れ/期限間近/廃止/取消）
- 許可区分名
- 許可番号
- 許可有効年月日
- 優良認定バッジ（該当時）
- 取扱品目バッジ（○=取扱, ◎=積替保管）

**操作**:
- **[+ 許可追加]** → 許可追加フォーム
- **カードクリック** → 許可詳細

### 6.2 許可追加フォーム (`openPermitForm`)

パンくず: 許可一覧 > 許可追加

| フィールド | ID | type | 必須 | 備考 |
|------------|----|------|------|------|
| 許可区分 | `pCategory` | select | ○ | マスター_許可区分から動的生成 |
| 許可番号 | `pNumber` | text | ○ | 全角→半角自動変換 |
| 許可年月日 | `pDate` | text (readonly) | ○ | 日付ピッカー |
| 許可有効年月日 | `pValidDate` | text (readonly) | ○ | 日付ピッカー |

**操作ボタン**:
- **保存** → `savePermit()` → 許可一覧に戻る
- **キャンセル** → 許可一覧に戻る

### 6.3 許可詳細 (`showPermitDetail`)

パンくず: 許可一覧 > 許可詳細

**B2レイアウト構成**:

```
┌─────────────────────────────────┐
│ [ヘッダー]                       │
│   許可区分名（タイトル）          │
│   許可番号（サブタイトル）        │
│   ステータスピル + 優良ピル       │
├─────────────────────────────────┤
│ [基本情報]                       │
│   許可区分 / 許可番号 / 許可年月日│
│   許可有効年月日 / 優良認定       │
├─────────────────────────────────┤
│ [取扱品目]                       │
│   品目×取り扱い状態テーブル       │
│   クリックで品目編集画面へ        │
├─────────────────────────────────┤
│ [更新/変更アクション] ※有効時のみ │
│   更新 / 変更（法14条の2）       │
├─────────────────────────────────┤
│ [ステータス] ※廃止or取消時のみ   │
│   状態 / 日付 / 理由 / 復活ボタン│
├─────────────────────────────────┤
│ [状態変更] ※有効時のみ           │
│   廃止フォーム / 取消フォーム     │
│   廃止理由 / 取消理由             │
├─────────────────────────────────┤
│ [履歴] 縦タイムライン             │
│   各バージョン: 修正/削除ボタン   │
└─────────────────────────────────┘
```

**ステータスバッジの判定優先順**:
1. 取消 → 赤ピル
2. 廃止 → 灰ピル
3. 期限切れ（有効年月日 < 今日） → 灰ピル
4. 期限間近（有効年月日 ≤ 今日+30日） → アンバーピル
5. 有効 → 緑ピル

#### 6.3.1 状態変更フォーム（許可詳細内、有効時のみ表示）

| フィールド | ID | type | 必須 | 備考 |
|------------|----|------|------|------|
| 廃止日 | `detail-abolish-date` | text (readonly) | ○※ | 日付ピッカー。廃止ボタン押下時に必須 |
| 廃止理由 | `detail-abolish-reason` | text | - | 自由入力 |
| 取消日 | `detail-cancel-date` | text (readonly) | ○※ | 日付ピッカー。取消ボタン押下時に必須 |
| 取消理由 | `detail-cancel-reason` | text | - | 自由入力 |

**操作ボタン**:
- **廃止** → `abolishPermitFromDetail()` → 確認ダイアログ → 許可詳細を再表示
- **取消** → `cancelPermitFromDetail()` → 確認ダイアログ → 許可詳細を再表示

#### 6.3.2 ステータス表示（廃止/取消時のみ表示）

**廃止時**: 状態ピル、廃止日、廃止理由（あれば）、[復活する]ボタン
**取消時**: 状態ピル、取消日、取消理由（あれば）、[復活する]ボタン

- **復活する** → `restorePermitFromDetail()` → 確認ダイアログ → 廃止日・取消日・理由をNULLクリア

### 6.4 許可編集フォーム (`showPermitEditForm`)

パンくず: 許可一覧 > 許可詳細 > 更新 / 変更 / 修正

3つのモードで共用:

| モード | 用途 | DB処理 | 遷移元 |
|--------|------|--------|--------|
| `renewal` | 更新（新バージョン作成） | 旧版CLOSE + 新版INSERT + 品目コピー | 詳細の[更新]ボタン |
| `change` | 変更（法14条の2） | 旧版CLOSE + 新版INSERT + 品目コピー | 詳細の[変更]ボタン |
| `edit` | 修正（既存バージョン直接修正） | UPDATE | 履歴VTLの[修正]ボタン |

| フィールド | ID | type | 必須 | renewal | change | edit |
|------------|----|------|------|---------|--------|------|
| 許可番号 | `edit-permit-number` | text | ○ | 引継ぎ | 引継ぎ | 編集可 |
| 許可区分 | `edit-permit-category` | select | ○ | 引継ぎ | 引継ぎ | 編集可 |
| 許可年月日 | `edit-permit-date` | text (readonly) | ○ | 空欄 | 空欄 | 編集可 |
| 許可有効年月日 | `edit-permit-valid` | text (readonly) | ○ | 空欄（+5年/+7年ショートカット付） | readonly（旧版から引継ぎ） | 編集可 |
| 有効開始日時 | `edit-permit-start` | text (readonly) | - | 非表示 | 非表示 | 表示（管理者オーバーライド可） |
| 有効終了日時 | `edit-permit-end` | text (readonly) | - | 非表示 | 非表示 | 表示（readonly） |
| 優良認定 | `edit-permit-excellent` | checkbox | - | 引継ぎ | 引継ぎ | 編集可 |
| 取扱品目 | `permit-edit-items` | インラインテーブル | - | 表示のみ | 編集可 | 編集可 |

**有効年月日ショートカット**（renewalモードのみ）:
- **+5年** → 許可年月日から5年後を自動セット
- **+7年** → 許可年月日から7年後を自動セット（優良認定時）

**管理者オーバーライド**（editモードのみ）:
- 有効開始日時の横に[管理者]リンク → クリックで `edit-permit-start-admin` テキスト入力に切替

**操作ボタン**:
- **保存** → モードに応じたDB処理 → 新版の許可詳細に遷移
- **キャンセル** → 許可詳細に戻る

### 6.5 許可品目編集 (`showPermitItemsView`)

パンくず: 許可一覧 > 許可詳細 > 取扱品目

マスター_品目の全品目を縦一覧で表示し、各品目に対して取り扱い状態をセルクリックで切替。

| 状態 | 表示 | 意味 |
|------|------|------|
| × | （空セル） | 未取扱 |
| ○ | ○ | 取扱可 |
| ◎ | ◎ | 積替保管可 |

**操作**: セルクリック → × → ○ → ◎ → × のサイクル切替 → 即時DBに保存

### 6.6 許可履歴タイムライン (`loadPermitHistoryVtl`)

縦タイムライン(VTL)形式で全バージョンを表示。

**各バージョンノードの表示内容**:
- バージョン期間（有効開始〜有効終了）
- ステータスピル（現行/過去/廃止/取消）
- 許可番号、許可区分名
- 変更差分表示（前バージョンとの比較）

**各ノードの操作**:
- **[修正]** → `showPermitEditForm(permitId, logicalId, businessId, "edit")`
- **[削除]** → `deletePermitVersion()` → 確認ダイアログ → 履歴VTL再読込

## 7. 施設タブ

### 7.1 施設一覧 (`tab-facilities`)

`loadFacilitiesForBusiness(businessId)` で表示。カードレイアウト。

**各カードの表示内容**:
- ステータスバッジ（有効/廃止/取消/休止/失効）

**ステータスバッジの判定優先順**:
1. 取消 → 赤ピル
2. 廃止 → 灰ピル

4. 失効（有効終了日時あり） → 灰ピル
5. 有効 → 緑ピル

### 12.4 操作の3分類

| 操作 | 意味 | DB処理 | 履歴への影響 |
|------|------|--------|-------------|
| **更新/変更** | 新バージョン作成 | 旧版の有効終了日時をCLOSE → 新版INSERT | 旧版が履歴に残る |
| **修正** | 既存バージョンの直接修正 | UPDATE | 履歴は変わらない |
| **状態変更** | ライフサイクル遷移 | UPDATE（廃止日/取消日等を設定） | バージョンは増えない |
