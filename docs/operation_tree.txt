廃棄物処理業許可管理システム 操作ツリー (v5.4)
================================================

ホーム
├── 事業者一覧
│   ├── [+ 新規登録] → 事業者登録フォーム
│   └── 各事業者
│       └── [詳細] → 事業者詳細
│           ├── 基本情報（事業者名・住所・電話番号）
│           ├── [編集] → 事業者編集フォーム
│           ├── [削除]
│           ├── 許可タブ
│           │   ├── [+ 許可追加] → 許可追加フォーム（区分・番号・日付・優良認定）
│           │   └── 各許可
│           │       └── [詳細] → 許可編集画面
│           │           ├── 許可番号・区分・日付・優良認定・取消/廃止
│           │           ├── 取扱品目一覧（〇取扱/◎積替保管/×なし、クリック切替）
│           │           ├── [保存] [キャンセル]
│           │           └── [履歴を見る] → 許可履歴一覧
│           │               ├── [+ 履歴追加] → 新規履歴→編集
│           │               └── 各履歴 [編集] → 許可編集画面
│           ├── 施設タブ
│           │   ├── [+ 施設追加] → 施設追加フォーム
│           │   └── 各施設
│           │       └── [詳細] → 施設編集画面
│           │           ├── 種別・場所・許可番号・各日付
│           │           ├── [保存] [キャンセル]
│           │           ├── [処理能力] → 処理能力一覧
│           │           │   ├── [+ 品目追加]
│           │           │   └── 各品目 [編集] [削除]
│           │           └── [履歴を見る] → 施設履歴一覧
│           │               ├── [+ 履歴追加] → 新規履歴→編集
│           │               └── 各履歴 [編集] → 施設編集画面
│           ├── 車両タブ
│           │   ├── [+ 車両追加] → 車両追加フォーム
│           │   └── 各車両
│           │       ├── [廃車] / [復活]
│           │       └── [削除]
│           └── 役員タブ
│               ├── [+ 役員追加] → 役員追加フォーム
│               └── 各役員
│                   ├── [退任] / [復帰]
│                   └── [削除]
├── 検索メニュー
│   ├── 事業者検索 → キーワード検索 → 結果一覧 → [詳細]
│   ├── 許可検索 → 条件検索（区分・期限・品目AND/OR） → 結果一覧 [CSV出力]
│   ├── 施設検索 → キーワード・種別検索 → 結果一覧
│   ├── 車両検索 → キーワード検索（廃車含む） → 結果一覧
│   └── 役員検索 → キーワード検索（退任者含む） → 結果一覧
├── 統計情報
│   ├── 事業者数・許可数・施設数
│   ├── 許可数推移グラフ（許可区分別、全年表示）
│   ├── 期限切れ間近の許可一覧 [CSV出力]
│   └── 処理能力集計（施設種別・品目別）
├── 設定
│   ├── データベース設定（パス・接続状態）
│   └── マスター設定（15種類）
└── テーマ切り替え（ライト/ダーク）
