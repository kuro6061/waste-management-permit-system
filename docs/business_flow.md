# 業務フロー: 許可操作と日付決定

**バージョン**: 1.0
**作成日**: 2026-03-12
**ステータス**: ユーザー確定済み

---

## 1. 概要

本書は廃棄物処理業の許可に関する操作種別の判定と、各操作における日付決定ルールを定める。
許可証の法的な日付（A軸）とシステム版管理の日付（B軸）を分離して管理する。

### 日付の2軸管理

- **A軸（許可証の日付）:** 許可年月日・許可有効年月日。許可証に記載される法的な日付。変更不可の事実記録。
- **B軸（システム管理の日付）:** 有効開始日時・有効終了日時。システム内部で「どの版が現在有効か」を管理するための日時。

---

## 2. 操作種別の判定フロー

```
許可に関する操作が発生
    │
    ├─ 新しい業者の許可か？ ─── Yes ──→【新規作成】へ
    │
    ├─ 既存許可の有効期限が切れているか？
    │     │
    │     ├─ Yes（失効済み） ──→【失効新規】へ
    │     │
    │     └─ No（有効期間内）
    │           │
    │           ├─ 許可の有効期限が近づいている？
    │           │     └─ Yes ──→【更新】へ
    │           │
    │           ├─ 許可内容（品目・施設等）に変更がある？
    │           │     └─ Yes ──→【変更】へ
    │           │
    │           └─ 既存データの誤り・記載ミスの訂正？
    │                 └─ Yes ──→【修正】へ
```

---

## 3. 日付決定ルール一覧

### 3.1 業許可

| 操作 | 許可年月日(A軸) | 許可有効年月日(A軸) | 有効開始日(B軸) | 有効終了日(B軸) |
|------|----------------|-------------------|----------------|----------------|
| **新規作成** | 決裁日（手入力） | 許可年月日+5年（優良+7年） | 許可年月日 | 許可有効年月日 |
| **更新** | 決裁日（手入力） | 従前の許可有効年月日+5年（優良+7年） | 許可年月日（= 決裁日） | 許可有効年月日 |
| **変更** | 従前を引き継ぐ | 従前を引き継ぐ | 決裁日 | 従前を引き継ぐ |
| **失効新規** | 新規作成と同じ | 新規作成と同じ | 新規作成と同じ | 新規作成と同じ |
| **修正** | 変更しない | 変更しない | 変更しない | 変更しない |

**旧レコードの閉鎖（更新・変更時）:**
- 更新時: 旧レコードの有効終了日 = 新許可年月日の前日
- 変更時: 旧レコードの有効終了日 = 変更決裁日の前日

### 3.2 施設

| 操作 | 許可年月日(A軸) | 有効開始日(B軸) | 有効終了日(B軸) |
|------|----------------|----------------|----------------|
| **新規作成** | 入力日 | 入力日 | NULL（無期限） |
| **変更** | 従前を引き継ぐ | 決裁日 | 従前を引き継ぐ（= NULL） |
| **修正** | 変更しない | 変更しない | 変更しない |
| **廃止** | - | - | 廃止日 |

**業許可との違い:**
- 施設許可には有効期限の定めがないため、有効終了日は原則NULL
- 「更新」の概念がない
- 施設の「許可年月日」は施設の設置許可日（業許可の許可年月日とは別）

## 4. 各操作の詳細フロー

### 4.1 新規作成

```
許可の決裁が完了
    │
    ├─ 入力日 = 今日か？
    │     │
    │     ├─ Yes → 許可年月日 = 今日
    │     │        有効開始日 = 今日
    │     │
    │     └─ No（過去の決裁を遡って入力）
    │           → 許可年月日 = 実際の決裁日（手入力）
    │             有効開始日 = 許可年月日
    │
    ├─ 優良認定か？
    │     ├─ Yes → 許可有効年月日 = 許可年月日 + 7年
    │     └─ No  → 許可有効年月日 = 許可年月日 + 5年
    │
    └─ 有効終了日 = 許可有効年月日
```

### 4.2 更新

```
更新の決裁が完了
    │
    ├─ 従前の許可情報を取得
    │     従前の許可有効年月日 = A
    │
    ├─ 許可年月日 = 決裁日（手入力）
    │
    ├─ 優良認定か？
    │     ├─ Yes → 許可有効年月日 = A + 7年
    │     └─ No  → 許可有効年月日 = A + 5年
    │
    ├─ 旧レコード: 有効終了日 = 新許可年月日の前日
    │
    ├─ 新レコード: 有効開始日 = 許可年月日（= 決裁日）
    │
    └─ 新レコード: 有効終了日 = 許可有効年月日
```

**みなし有効期間の扱い:**
旧許可の有効期限と新許可の決裁日の間にみなし有効期間が発生する場合、旧レコードは「期限切れ」として表示される。更新登録が完了した時点で旧レコードの有効終了日が「新許可年月日の前日」に更新され、新レコードが有効になる。

### 4.3 変更

```
変更の決裁が完了
    │
    ├─ 従前の許可情報を取得
    │     従前の許可年月日     = そのまま引き継ぐ
    │     従前の許可有効年月日 = そのまま引き継ぐ
    │     従前の有効終了日     = そのまま引き継ぐ
    │
    ├─ 許可年月日     = 従前を引き継ぐ（変更不可・グレーアウト）
    ├─ 許可有効年月日 = 従前を引き継ぐ（変更不可・グレーアウト）
    │
    ├─ 有効開始日 = 決裁日（手入力、デフォルト: 今日）
    │
    ├─ 旧レコード: 有効終了日 = 決裁日の前日
    │
    └─ 有効終了日 = 従前を引き継ぐ
```

### 4.4 失効新規

新規作成と同じフローに従う。許可が失効しているため、完全に新しい許可として扱う。
DBに「失効新規フラグ」（YESNO型）をセットし、履歴タイムラインで「失効新規」ラベルを表示する。

### 4.5 修正

```
既存データの誤り訂正
    │
    └─ 全ての日付フィールドを変更しない
       （許可年月日・許可有効年月日・有効開始日・有効終了日すべて維持）
       ※ 修正は同一版の内容訂正であり、版管理上の日付は不変
```

## 5. 過去日付での入力ルール

- **許可年月日は法的制約により決裁日でなければならない。** 入力日ではない。
- 実務上、決裁日と入力日がずれるケースは半々程度ある。
- 許可年月日のデフォルト値 = 今日の日付（手入力で過去日付に変更可能）

```
操作の入力（システムへの登録）
    │
    ├─ 許可年月日 = 実際の決裁日を手入力（デフォルト: 今日）
    │     ※ 法的制約: 許可年月日は決裁日でなければならない
    │
    ├─ 操作種別による有効開始日の決定:
    │     │
    │     ├─【新規作成・失効新規】
    │     │     有効開始日 = 許可年月日（= 決裁日）
    │     │
    │     ├─【更新】
    │     │     有効開始日 = 許可年月日（= 決裁日）
    │     │     旧レコードの有効終了日 = 新許可年月日の前日
    │     │
    │     ├─【変更】
    │     │     有効開始日 = 決裁日（= 変更が効力を持つ日）
    │     │
    │     └─【修正】
    │           有効開始日 = 変更しない
    │
    └─ その他の日付は各操作フロー（§4）に従う
```

---

## 6. バリデーション

- 業許可: 許可有効年月日 = 有効終了日 であること（新規・更新・変更時）
- 施設: 有効終了日は原則NULL（廃止時のみ設定）
- 有効開始日 < 有効終了日 であること（有効終了日がNULLでない場合）

---

## 7. 優良認定

- 全パターン（新規・更新・随時申請）に対応する
- 優良認定は版ごとの属性。更新時にOFFにすれば通常許可（+5年）に戻る
- 優良認定トグルは新規・更新・変更いずれの画面でも操作可能
