# 廃棄物処理業許可管理システム データベース設計書

**バージョン**: 4.8
**最終更新**: 2026-03-11

---

## 概要

このデータベースは廃棄物処理業の許可情報を管理するシステムです。
許可と施設については履歴追跡機能を持ち、過去の状態を参照可能です。

---

## 履歴追跡機能について

### 対象テーブル
- **許可**: 履歴追跡あり
- **施設**: 履歴追跡あり
- **役員**: 履歴追跡なし
- **車両**: 履歴追跡なし

### 履歴追跡の仕組み
- `論理ID`: 同一エンティティを識別するID（変更があっても同じ値）
- `物理ID`: 各レコードのユニークID（AUTOINCREMENT）
- `有効開始日時`: このレコードが有効になった日時
- `有効終了日時`: NULL=現在有効、値あり=過去レコード

更新時の動作:
1. 現在有効なレコードの`有効終了日時`に現在日時を設定
2. 新しいレコードを作成（同じ論理ID、新しい物理ID）
3. 新レコードの`有効開始日時`に現在日時、`有効終了日時`はNULL

## クエリ例

### 現在有効な許可を取得
```sql
SELECT * FROM 許可 WHERE 有効終了日時 IS NULL
```

### 特定の許可論理IDの履歴を取得
```sql
SELECT * FROM 許可
WHERE 許可論理ID = [論理ID]
ORDER BY 有効開始日時 DESC
```

### 現在有効な施設を取得
```sql
SELECT * FROM 施設 WHERE 有効終了日時 IS NULL
```

### 事業者の現在有効な許可と施設を一覧
```sql
SELECT 事業者.事業者名, 許可.許可番号, 許可.許可有効年月日
FROM 事業者
INNER JOIN 許可 ON 事業者.事業者ID = 許可.事業者ID
WHERE 許可.有効終了日時 IS NULL
```
