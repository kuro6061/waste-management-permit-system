# CSVバックアップ レコードレイアウト仕様書

## 概要

本書は、産業廃棄物許可業者管理システムのバックアップ・リストア機能で使用するCSVファイルのレコードレイアウトを定義する。

### 注意事項

- **レコードレイアウトの変更厳禁**: 項目の順序を変える、項目数を増減させる等の変更を行うと、リストア処理でデータを読み込めなくなる。
- **取扱廃棄物の項目順序**: 予備項目も使用しているため、フィールド名（`gchk01`〜`gchk31`）と日本語ラベルの並びが前後している箇所がある。
- **文字コード**: Shift_JIS
- **区切り文字**: カンマ（`,`）

---

## 許可区分別レイアウト一覧

| 許可区分 | フィールド数 | 取扱廃棄物フィールド | 備考 |
|---|---|---|---|
| 産業廃棄物 収集運搬業 | 46 | gchk01〜gchk23（23品目） | gclass＝積替保管の有無 |
| 産業廃棄物 処分業 | 47 | gchk01〜gchk23（23品目） | gclass＝処分区分(中間), gclass2＝処分区分(最終) |
| 特別管理産業廃棄物 収集運搬業 | 54 | gchk01〜gchk31（31品目） | gclass＝積替保管の有無 |
| 特別管理産業廃棄物 処分業 | 55 | gchk01〜gchk31（31品目） | gclass＝処分区分(中間), gclass2＝処分区分(最終) |

> 処分業は収集運搬業に対し `gclass2`（処分区分(最終)）が追加されるため、フィールド数が1つ多い。
> 特別管理は取扱廃棄物の品目数が23→31に増えるため、フィールド数が8つ多い。

## 許可区分間の構造比較

4つの許可区分は以下の共通構造を持つ。差異は中間ブロックのみ。

```
[共通情報] → [区分固有フィールド] → [取扱廃棄物] → [管理情報・付加情報]
```

### 構造の差異まとめ

| 区分 | 区分固有フィールド | 取扱廃棄物品目数 |
|---|---|---|
| 産廃 収集運搬 | gclass（積替保管） | 23品目（gchk01〜23） |
| 産廃 処分 | gclass（中間）+ gclass2（最終） | 23品目（gchk01〜23） |
| 特管 収集運搬 | gclass（積替保管） | 31品目（gchk01〜31） |
| 特管 処分 | gclass（中間）+ gclass2（最終） | 31品目（gchk01〜31） |
